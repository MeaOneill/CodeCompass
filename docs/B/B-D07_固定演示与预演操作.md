# 第七日：成果入口与固定操作

不需要你运行pytest或读取长JSON来替Agent验收。技术检查由Agent执行。真实人员只能由实际自愿参与者操作，不能用AI作答代替。

## 打开入口

项目目录内只需一条启动命令，终端保持打开：

```powershell
./scripts/B/start_d07.ps1
```

浏览器打开 http://127.0.0.1:8781/ 。首次新机器没有环境时，入口会创建Python3.12虚拟环境并安装已有hash锁定依赖；未装Python则明确提示。不开公网端口，不读取API密钥，不产生模型费用。

## 固定演示（同一匿名记录）

1. 自愿同意开发预演，完成四题共同初测；不会可以明确跳过。
2. 选择boltons的task_002与Ours，开始计时。查看固定版本、行号和路线依据，读完当前材料后点完成。
3. 做一次独立短测，看反馈页。路线不变也保留，不要求答成某个结果。
4. 回到源码继续阅读；独立任务可上传五个提交文件，或记录开发预演尚未提交代码的实际情况。不把空文件/备注当任务成功。保存提交或明确退出，不能伪造成功。
5. 进入画像页核对证据和任务历史，登记跨仓库引用；选择more-itertools功能案例，阅读真实chunked和take源码，再完成不同的独立新题。
6. 保存第二轮提交，回画像看源项目证据仍在、目标新题另记；查看第一轮的Issue准备，注意历史快照日期。更多仓库未取到Issue则显示未获取。
7. 若换下一位，先结束当前任务，再在任务选择页点“结束本次，切换下一位预演者”。它只清除当前浏览器编号，不删除数据库，不替下一位勾同意。

两人各操作一次，不能因答案或路线不变重新刷题追结果；组织者登记实际总时长、是否可承受、卡点/退出和不同真实人员确认。预演者排除正式样本。不会yield不是验收失败，允许跳过；不要求参与者替开发者判断算法有效。

## 数据与恢复

真人数据库默认在ignored的experiments/B/B-D07-human-live01/state.sqlite3。刷新读取同一编号；重启用同一数据库，异常时间不补0。源代码更新时拒绝把旧记录重标新版。自动开发演示用scripts/B/demo_d07.py，输出明确test_fixture，不属于真人预演。

另一台机器先检出交接中的准确分支/SHA，再用同一入口；不能只看GitHub网页就写双机通过。最终以交接、版本manifest、运行记录和真实人员/机器回执为准。
