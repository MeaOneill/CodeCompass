# 当前固定引导与后续自动生成

当前B-D07的两组任务讲解在app/B_D07/guide.js中固定编写，前端使用A的真实规划路线和固定源码。用户输入任意仓库链接后生成整套讲解、任务与引导尚未接入，不应声称已具备。页面AI入口只复制上下文，不调用模型。

建议后续链路：链接→固定仓库commit/许可/源码快照→解析函数及依赖→根据目标与画像由规划器安排路线→后端给大语言模型发送当前单元的必要源码、行号、目标、画像摘要和路线理由→输出结构化引导→校验引用、版本及字段→缓存→前端展示。

LLM适合生成通俗说明、术语、例子、阅读动作、理解问题和明确的完成标准。依赖与预算约束、路线排序、掌握证据及独立评分仍由现有算法/评估器处理。不能用模型措辞代替路径算法，不给生成接口终测答案。生成新任务时应走独立评审，不能未经审核填满正式题池。

密钥只在服务端本地环境，浏览器调用本项目后端；记录模型标识、prompt版本、源码SHA、输入hash、原始输出、token/时间/费用及修复次数。按仓库commit+目标+引导版本缓存。API失败时准确显示暂不可用或原固定缓存，不伪造新生成结果。学习阶段AI帮助在各比较方法间一致，正式方案需另版批准。

本说明是后续接口设计，不是已经运行的自动生成结果；本次未调用API、未产生模型费用。
