# CodeCompass参与者招募与预演草案

本轮只准备材料，没有实际邀请、报名或参与者数据。由团队成员自行邀请；Agent不代发消息。正式方案与任务在D06前审核冻结，当前不开展正式效果实验。

招募对象为有Python基础、希望了解开源代码的自愿参与者。正式目标12—18人，两位开发者及2位预演者不计正式样本。预计统一初测约10分钟，三轮不同任务，每轮学习/测验/终测总上限25分钟，另有休息；预演后再确认总时长。达不到计划人数时按实验协议在看正式结果前决定降级，不能拿开发者或AI夹具补人数。

向参与者说明：目的为探索代码阅读路线的可用性，任务表现不用于课程考核；可以不回答、休息或随时停止，无须解释，不影响任何权益。记录匿名编号、是否有Python/代码阅读经验、是否熟悉仓库、任务时间、输出、必要交互事件；不收姓名、学校、电话、账号、学号。避免录制桌面或其他个人内容；若确需录屏另行征求具体同意，不把参与意愿默认为录屏授权。

编号由组织者按P001等产生，联系方式与编号映射如确有必要由人类另存受限位置，不进入Git。参与者保留撤回码；在去标识汇总前可以凭码要求删除原始数据。去标识汇总后无法追溯删除的界限在开始前说明，不承诺永远可定位删除。实际保存期限、可访问研究者、费用/补偿（未确定）由人类明确后再邀请；本草案不代签同意。

初测候选：Python生成器创建与next的区别；迭代器一次性消费；None和未传参数的区别；异常类型与默认值；字节/文本转换。每题必须有不同item_id，答案由B评估侧保管，不能将同题重答当独立证据。正式题目/评分与初测题不同，不能提前透露终测答案。

预演步骤：先由不计正式样本的人读任务说明并复述；计时完成独立题，记录卡住位置/说明歧义/帮助次数/真实用时；两位人类按盲于方法rubric独立评分并记录分歧；修订题目后重置候选版本，不把预演题继续称冻结题。当前所有time_limit=25是设计上限，NOT_PILOTED。

退出/失败：退出保留匿名退出状态与缺失原因（可不提供），不补造结果；超时截断用时按协议，成功者用时另列。方法特有诊断/模型帮助均计时，终测期间不得使用解答型AI。当前没有参与者成功率、招募人数或人时可以报告。
