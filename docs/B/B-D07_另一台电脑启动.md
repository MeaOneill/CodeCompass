# 另一台Windows实体电脑验证

两人新版预演已按用户明确确认通过。当前只剩此项；不需要为了此项重新测试所有代码题或配置API密钥。

先确认这确实是另一台电脑，安装有Git及Python3.12。在PowerShell使用全新目录，避免覆盖已有仓库：

```powershell
cd $env:USERPROFILE
git clone --branch codex/B-D07-loop --single-branch https://github.com/MeaOneill/CodeCompass.git CodeCompass-B07-check
cd CodeCompass-B07-check
git rev-parse HEAD
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\B\start_d07.ps1
```

仅此子进程使用ExecutionPolicy Bypass以运行本仓库已授权脚本，不修改全局执行策略。如原终端已允许脚本，也可直接运行 .\scripts\B\start_d07.ps1 。第一次会创建.venv并安装锁定依赖，需要等待。保持窗口开着，看到服务已启动后，在这台电脑的浏览器打开 http://127.0.0.1:8781/ 。localhost指当前电脑，不能用另一电脑的链接替代本地启动。

走一遍：说明/初测→源码/小题/反馈→提交或未完成退出→学习记录→第二仓库再测与阅读记录；刷新核对记录仍在，查看Issue历史日期。不要求代码题做对。

另开PowerShell保存去标识化机器与HTTP回执：

```powershell
cd "$env:USERPROFILE\CodeCompass-B07-check"
$env:PYTHONPATH='src'
$run='B-D07-machine2-'+(Get-Date -Format yyyyMMdd-HHmmss)
.\.venv\Scripts\python.exe scripts/B/verify_d07_install.py --run-id $run --owner B --executor machine2_operator --compare-machine 2fffa737941617ad929bb0a97f0b7b15ee4855ce9b375a42d1cf0bcba17b0b3a
```
