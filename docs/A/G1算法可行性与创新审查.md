## 已落实的代码与普通拓扑/检索的区别

| 增量 | 可执行入口 | 决策/限制 |
|---|---|---|
| 状态 | learner/model.py initial_state/update_evidence/planning_rows | 用户隔离、纯函数、重复item_id按概念去重、独立pass/fail证据；阅读和自报不更新 |
| 掌握门控 | mastery_gate | 当前项目Beta(1+pass,1+fail)的0.1分位下界>=0.7才跳过；无证据不跳；模拟显式隔离 |
| 闭包 | planner/core.py reverse_closure | 从目标单元反向硬先修；共享前置仅一次；环检测；可跳过有证据或此前已覆盖的整单元 |
| 联合选择 | greedy_plan | 对候选闭包的新增目标覆盖/增量去重成本贪心；零成本优先，平手按成本/ID确定；预算过滤 |
| 原因链 | reason_trace/candidate_attempts | 每个单元、固定源码、根目标、增量成本、门控证据ID、阻塞候选可追踪 |
| 合法性 | check_plan / plan_request | 不调用贪心选择，顺序回放先修/预算/覆盖/状态；接口先校验契约、固定快照字节与span |

这是B2-initial开发贪心基线骨架，不是后续beam/Ours。不以自拟名字宣称首创；闭包、集合覆盖式贪心、Beta门控都是已有机制。差异是本项目把独立证据、来源、未审核教学边门禁和预算放入同一实现；是否有研究收益仍需消融、不同任务和真人学习评估。相关研究见docs/related_work.md。

Beta整数计数计算依据[NIST DLMF 8.17.5](https://dlmf.nist.gov/8.17.E5)二项式尾和，用64次二分下括号；不是拟合/校准的知识追踪模型，仅支持正整数、有限范围计数。掌握阈值为开发配置，不是已验证的教育结论。
