# A-D04：完整比较接口与可读算法

版本D04-cost-only-v0.1；基于B-D03 5b3db98407ea47e1f26c7ff4cd7594cb42305aea。报告与系统以同一run的input_manifest/code_snapshot和最终业务检查点锁定。此轮实现搜索比较，不代表说明书全部候选机制完成。

## 输入、目标与边界

三个方法共用同一request/units/state/config，复用D03的独立证据Beta门控q=.1、τ=.7。未知能力不跳过，阅读不更新掌握。成本固定、非负、按选中单元ID去重；真实数据为源码行数代理，夹具为显式代理，均非分钟。仅优化J(P)=Σc(v)。重复概念惩罚、个性化成本拟合、诊断、切换惩罚和反馈稳定性目标尚未实现，不声称本轮完整覆盖它们。

硬教学前置满足条件：指定前置单元已选，或该单元的全部概念已由证据/此前材料覆盖。软边不成硬约束；真实边仍pending/soft，夹具审核标记明确不是人类。可替代材料覆盖概念可打破结构夹具的依赖环；不能简单把图有环判成数学无解。

预算统一定义cost <= B + 1e-9绝对容差。B2保持原代码/候选/阈值/成本；新方法用math.fsum按排序ID累加，旧B2的逐项加法保留，差异仅浮点舍入，独立回放同容差核对。精确差距只对完整可行路线计算，失败的partial cost不是成功成本、不能补零。

## beam伪代码

```text
验证契约、固定源字节/span、能力原始证据与请求聚合
M = 通过模型证据门控的概念
frontier = {空路线}; seen[空集合] = 空路线; incumbent = 无
对至多 n+1 轮：
    检查协作式wall-clock截止；到期返回TIMEOUT（可保留可行incumbent）
    对frontier按(未覆盖目标数, 总成本, 长度, 路线字典序)排序：
        若目标全覆盖，更新incumbent；否则：
        对尚未选、能增加概念的每个单元（包括非目标先修材料）：
            求未满足硬先修的反向闭包，共享部分不重复计费
            闭包环 -> 记录阻塞；预算超限 -> 记录阻塞
            若已有incumbent，丢弃严格更贵的非负成本扩展
        按(负新增目标增益/增量成本, 增量成本, 根ID)排序
        保留前C个候选，逐项记录被截断根ID
        新路线按frozenset(已选ID)去重，同集合保留字典序小的合法路线
        更新incumbent；达到扩展上限时记录EXPANSION_LIMIT
    新状态按固定rank保留前W个，记录丢弃路线
    无新frontier则结束
若有完整incumbent -> FEASIBLE；否则NO_FEASIBLE_FOUND
beam任何结果 optimality_claim=false
```

同集合去重成立仅因本轮固定可加成本、覆盖由已选集合决定、未来合法性不依赖此前路线顺序；若后续加入切换/顺序惩罚，必须扩展状态键后重新验证，不能沿用这一等价关系。

默认W=16、每状态C=50、max_expansions=100000、搜索wall-clock=30秒。候选池不因方法改变，C是扩展截断；宽度1/4/16/32均保存原始日志。墙钟从输入验证和证据门控后开始，在轮/根候选/扩展间协作检查，单次闭包不强行中断，故可能小幅超出截止；不是整个进程硬时限。验证、精确证明和图表耗时另计。

确定性保证：相同输入、配置且未被墙钟中断时，排序ID/固定平局使路线完全一致；单元输入顺序置换测试通过。真实墙钟受机器负载影响，中断点/partial route可能不同，elapsed不承诺逐字相同。可复现截断应使用扩展上限；墙钟作为运行保护。截断或超时从不标最优。

## 小图精确DP与独立校验

```text
ids按ID排序；reachable[0] = 空路线
遍历mask = 0 .. 2^n-1（n <= 12）：
    若mask可达：计算证据+该集合的覆盖
    对每个未选单元：
        在当前覆盖下逐个检查硬先修，不调用beam闭包
        若合法且加入后成本在预算容差内，更新next_mask
        同mask保留字典序最小路线
    完整目标的mask按(成本, 长度, 路线)更新精确最优
遍历完成才生成全部reachable_masks与输入hash证书
```

证书只证明固定候选、当前证据、硬教学图、非负代理成本和预算内的结论。独立comparison_validator不调用beam/greedy/exact/闭包：路线逐步重放；证书通过另一方向的递推验证——mask可达当且仅当能移除一个当时合法的末单元并留下可达前缀。重算全部可达集合、成本与最优路线合法性；输入hash/模型不符直接拒绝。

`solve_request(... method='beam'|'B2'|'exact', options=..., certify_small=False)`为新增入口，返回(result,details)。原plan_request与__init__不改，B既有应用仍使用旧贪心，B-D04需要显式接线，不能称现在GUI已支持beam。certify_small=True时，仅对<=12且beam未找到的输入调用精确DP；确实无解且通过独立验证才改INFEASIBLE_PROVEN；精确有解时保留启发式失败并保存witness，不用精确解偷偷替beam补成绩。超过12只记录证书跳过，不伪造证明。

| 状态 | 实际触发材料 | 含义 |
|---|---|---|
| FEASIBLE | cost_gap / beam | 独立重放完整合法；不保证最优 |
| NO_FEASIBLE_FOUND | greedy_failure，W=1/C=1 | 有界搜索未找到；精确witness说明其实有解 |
| INFEASIBLE_PROVEN | unreachable + 完整精确证书 | 此输入集合/预算模型下确实无解 |
| TIMEOUT | cost_gap，wall-clock=0 | 实际调用耗尽零秒搜索预算；不是伪造状态字符串 |

所有触发均保存status_examples/input/output与证书。TIMEOUT即便带完整incumbent，也保留TIMEOUT并单列其可行性，不写最优。

## 复杂度上界与截断

令n为单元数、e为硬边数、K为概念数，W为beam宽，C=min(配置候选上限,n)。以下是保守Python集合/列表实现上界，不是实测延迟；整数/字符串操作按通常有限ID处理。证据读取/Beta计算及source校验另算。

一次闭包含集合扫描/递归栈检测/依赖排序，取保守D=O((n+e)(n+K+log(n+e+1)))；一次状态rank取R=O(nK+n log(n+1))。至多n+1轮，每轮至多W个状态、每状态检查n个根：时间上界O(n[WnD + Wn log(n+1) + WCn + WC log(WC+1)(R+n)])。候选截断发生在根闭包计算之后，所以C不会消除全部n根的分析成本。

不含日志的frontier/seen/候选路线存储保守O(n²WC + n+e+K)。原始日志还记录每次候选/丢弃路径，保守O(n²W(n+C))；日志也有有限轮数上界，但不是常数内存。扩展上限与墙钟保护限制实际搜索；没有任意大图性能承诺。

精确DP/独立证书校验可取保守O(2^n n(n+e)(n+K+log(n+1)))时间、O(2^n n+n+e+K)空间（含路线代表）。n<=12硬限制把mask数量封顶4096，13单元精确请求拒绝。不能推广为一般图可高效精确解或beam近似保证。
