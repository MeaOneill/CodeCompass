# CodeCompass

面向开源项目理解的能力感知学习路径规划与贡献导航系统。

## 当前阶段

项目当前处于研究规划与开发环境建立阶段。主算法、软件闭环及实验尚待实现和验证；文档中的规模、效果假设和日程不代表已经取得的结果。

主算法方向：结合用户实际能力、项目结构、学习难度与任务目标，联合选择学习内容和学习顺序。诊断测验、反馈重规划作为候选增强机制。

## 从哪里开始

- `CodeCompass计划/README.md`：规划包入口。
- `CodeCompass计划/02_每日任务与验收.md`：每日研发、图表、Git维护与验收。
- `CodeCompass计划/05_Git远程仓库创建与日常维护.md`：首次配置与双机接力教程。
- `CodeCompass计划/tracking/STATUS.md`：实际进展，不以计划代替完成状态。
- `Word文档/V6.2_Git更新版/`：当前Word总说明书、成员A/B每日任务和Git教程。

## 协作

每轮在任务分支工作，先同步实际前置版本，结束时验证并更新日志、交接与图表索引，再提交和推送。未完成任务保留检查点；经复核的版本合入main。

当前开发仓库为私有协作仓库。第三方资源按其许可使用，公开范围和本项目许可证应在资源核查后确认；没有许可证不代表他人可任意再分发。
