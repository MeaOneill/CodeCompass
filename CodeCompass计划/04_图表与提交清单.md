## 报告正文建议15页分配

以官方九部分为框架，可合并：1页概述/需求；1页相关方法与差异；1页系统与AI/开源融合；3页算法/公式/伪代码/复杂度；2页数据/基线/公平性；3页结果/消融/错误；1页完整软件与案例；1页团队分工、AI审核和开发过程；1页开放复用、资源边界与风险；1页总结/限制/引用。封面与附件按最终模板安排，并实际核对正文页数。

资源使用清单、详细实验记录、任务示例、复现说明、额外图放附件；仍需保证提交PDF≤10MB。不要为了塞图缩成难读小字。主要结论要引用真实run_id对应的表，不写“预计提升”当结果。

## 约4分钟视频分镜

| 时段 | 展示内容 |
|---|---|
| 0:00—0:25 | 真实用户任务、固定路线的问题 |
| 0:25—1:10 | 仓库固定版本、短测、路径和源码依据 |
| 1:10—2:05 | 一次真实测验失败后的补学/重规划，解释算法决策 |
| 2:05—2:50 | 真实对照、消融和一个失败案例；不虚构数字 |
| 2:50—3:30 | 长期记录、跨项目证据示例、真实Issue准备建议 |
| 3:30—4:00 | 自主改进边界、复现命令和开放成果 |

27日试录，28日最终录制。没有实际跨项目功能则据实调整分镜并记录缺口。全片观看，检查声音、文字和画面，不仅看文件存在。

## 提交前检查（全部初始为未完成）

- [ ] 队长核查报名、缴费、成员和方向；官方截止10/30 20:00。
- [ ] 名称≤20字，简介≤300字，简介按问题—方案—实现—效果—开放成果组织。
- [ ] 报告PDF≤10MB，正文建议≤15页，逐页渲染无裁切/乱码。
- [ ] 资源表作为报告附件，版本、来源、许可、关键义务、自研边界完整。
- [ ] 说明AI辅助的环节以及团队如何审查、修改、验证，能讲清核心算法。
- [ ] MP4 3—5分钟、≤300MB，全片播放通过。
- [ ] 全部评审材料无学校名称、LOGO、指导教师信息，检查页眉、录屏桌面、路径、文件属性及评审可见成果页。
- [ ] 成果链接填写于平台“作品其他材料链接”，评审期持续可访问；访问方式测试通过。
- [ ] 源码/环境/固定配置/任务来源/原始结果可核查，数据许可允许的范围清楚。
- [ ] 个人数据、API密钥和无权再分发内容不进入公开包。
- [ ] 第二台电脑复现通过，锁定版本和提交材料一致。
- [ ] 记录提交时间、文件SHA256和平台接收回执，确认不是只保存草稿。

本阶段不强制制作决赛PPT；可保留报告提纲供晋级后使用。只有最终平台接收确认才记为“已提交”。
